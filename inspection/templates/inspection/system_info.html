Academic Positioning

This project is developed under SIH Problem Statement SIH26034 as an IoT and AI-assisted decision-support system for packaged-commodity verification.

Core Innovation: Combining OCR-based digital label verification with IoT-based physical measurement in a single unified inspection workflow.

The system strictly adheres to the following principles:

  • It does NOT claim that OCR itself determines legal culpability or invalidity.
  • It does NOT replace authorized Legal Metrology inspectors; it acts as an intelligent decision-support aid.
  • Weight variances are treated as Potential Discrepancies needing review subject to permissible maximum error tolerances under Second Schedule of LM Rules.
  • It does NOT issue government certifications or final penal orders.
Technology Stack
  • Backend Framework Python / Django 6.0
  • Frontend UI HTML5, CSS3, JS, Bootstrap 5
  • Image Processing OpenCV (cv2)
  • OCR Engine Tesseract OCR (pytesseract)
  • Database MongoDB (pymongo)
  • Hardware (Phase 11) ESP32 + HX711 + Load Cell
